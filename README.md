# LabVIEW 多传感器跌倒检测与分级报警系统

使用倾斜、运动和光敏信号完成采集、状态判断、分级提示、报警及本地数据记录。

## 打开与运行

1. 打开 `Fall_Detection.lvproj`，再打开 `Main.vi`。
2. 无硬件时关闭“硬件模式”，使用“倾斜（仿真输入）”和“运动（仿真输入）”检查流程。
3. 实物测试时先接好设备，勾选“硬件模式”后运行，确认硬件就绪、错误代码为 0。
4. 倾斜但仍在运动时进行提示；进入疑似判定后，确认期内恢复运动或姿态恢复可退出本次判定。
5. 倒计时阶段可取消；进入红色确认报警后，运动和取消操作均不能解除报警，需要手动复位。
6. SOS 持续约 2 秒可进入确认报警。复位前先释放 SOS，并恢复正常姿态。
7. 使用前面板“停止”结束，让程序关闭输出并释放设备。

默认疑似判定延时 5 秒、报警倒计时 30 秒。参数位于 `Config/P1_Runtime.ini`；日志由程序写入 `Data/Main_native_samples.csv`。
配置和日志位置由主程序目录确定，界面中保存的旧路径显示不代表必须放在某台电脑的固定目录。

## 主要模块

`Main.vi` 组织整个循环；`SubVI/YAV` 负责设备初始化、采集、输出和关闭；状态机负责状态转换；报警控制负责提示节奏；配置和日志模块分别处理 INI 和 CSV。
`Controls/State.ctl` 定义 NORMAL、SUSPECT、COUNTDOWN、ALARM、RESET 状态。

光照是环境电压信息，不是直接照度；运动信号也不能完全代表人体存在。本项目用于课程实验，不作为医疗报警设备。

## 环境与接线

Windows、LabVIEW 2020 32 位，以及匹配的 YAV/ADIO 采集卡驱动。LabVIEW 自带的 vi.lib 函数由本机安装环境提供。

|信号|通道|作用|
|---|---|---|
|倾斜模块数字输出|DI0|姿态变化输入|
|RCWL 运动模块输出|DI1|运动状态输入|
|光敏模块模拟输出|AI0|光照电压采集|
|蜂鸣器模块控制端|DO0|声音提示|
|继电器模块控制端|DO1|报警联动|

传感器和采集卡使用公共参考地。供电、电平及输出极性需要按实际模块确认。
